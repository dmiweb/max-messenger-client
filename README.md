# MAX Messenger Client

Небольшой веб-клиент для обмена текстовыми сообщениями в MAX через API GREEN-API.

**Демо:** https://dmiweb.github.io/max-messenger-client/

**Репозиторий:** https://github.com/dmiweb/max-messenger-client

## Возможности

- подключение авторизованного инстанса GREEN-API;
- создание чата по номеру телефона;
- отправка текстовых сообщений;
- получение входящих сообщений через long polling;
- отображение истории сообщений текущей сессии;
- поиск по чатам;
- адаптивный интерфейс для desktop и mobile.

На мобильных устройствах при ширине экрана до **700px** интерфейс переключается между списком чатов и выбранной перепиской.

## Архитектура

Проект организован по принципам **Feature-Sliced Design (FSD)**.

Основные слои:

- `app` — провайдеры и конфигурация приложения;
- `pages` — страницы;
- `widgets` — крупные составные блоки интерфейса;
- `features` — пользовательские действия;
- `entities` — бизнес-сущности;
- `shared` — переиспользуемый код и API.

## Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/dmiweb/max-messenger-client.git
```
### 2. Перейти в папку проекта

```bash
cd max-messenger-client
```
### 3. Установить зависимости

```bash
npm install
```
### 4. Запустить проект локально

```bash
npm run dev
```

После запуска Vite выведет локальный адрес приложения в терминале.

### Подключить GREEN-API

Для работы с сообщениями необходимо иметь авторизованный инстанс GREEN-API.

При запуске приложения укажите:

- `idInstance`
- `apiTokenInstance`

После авторизации можно создать чат, указав номер получателя в международном формате.
