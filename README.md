# MAX Messenger Client

Небольшой веб-клиент для обмена текстовыми сообщениями в MAX через API GREEN-API.

Приложение позволяет:
- подключить авторизованный инстанс GREEN-API;
- создать чат по номеру телефона;
- отправлять текстовые сообщения;
- получать входящие сообщения в режиме long polling;
- просматривать историю сообщений текущей сессии.

## Стек

- React 19
- TypeScript
- Vite
- React Router
- CSS Modules
- GREEN-API
- Lucide React

## Локальный запуск

### 1. Установить зависимости

```bash
npm install
```

### 2. Запустить проект

```bash
npm run dev
```
